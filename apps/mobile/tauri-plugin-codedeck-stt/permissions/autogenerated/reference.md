## Default Permission

Default permissions for the codedeck-stt plugin: fire the system speech recognizer and read its result

#### This default permission set includes the following:

- `allow-recognize-speech`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`codedeck-stt:allow-recognize-speech`

</td>
<td>

Enables the recognize_speech command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`codedeck-stt:deny-recognize-speech`

</td>
<td>

</td>
</tr>
</table>
