## Default Permission

Default permissions for the mesh plugin

#### This default permission set includes the following:

- `allow-join-mesh`
- `allow-leave-mesh`
- `allow-mesh-status`
- `allow-mesh-action`
- `allow-open-wireless-debugging`
- `allow-prepare-adb`
